# Manual Penggunaan

## Pendahuluan
Dokumen ini bertujuan untuk memberikan panduan lengkap mengenai penggunaan aplikasi ini.

## Instalasi
1. Pastikan Anda memiliki Python 3.x terinstal di perangkat Anda.
2. Clone repository ini menggunakan perintah:
   ```bash
   git clone https://github.com/RyoFs/werehouse-kompas.git
   ```
3. Pindah ke direktori proyek:
   ```bash
   cd werehouse-kompas
   ```
4. Install semua dependensi yang diperlukan:
   ```bash
   pip install -r requirements.txt
   ```

## Cara Menggunakan
1. Untuk menjalankan aplikasi, gunakan perintah:
   ```bash
   python main.py
   ```
2. Ikuti instruksi yang diberikan dalam aplikasi untuk menyelesaikan proses yang Anda inginkan.

## Troubleshooting
Jika Anda mengalami masalah, pastikan untuk memeriksa:
- Apakah semua dependensi telah terinstall dengan benar?
- Apakah Anda menjalankan aplikasi di versi Python yang didukung?
